# Колоди та картки

## Огляд колод

| `BoardCardType` | Дефолтний розмір | Де відкривається | Призначення |
|---|---:|---|---|
| `SmallBusiness` | 53 | Бізнес | Купівля малого бізнесу. |
| `MediumBusiness` | 50 | Бізнес | Купівля середнього бізнесу. |
| `BigBusiness` | 50 | Великий бізнес або прогресія бізнесу | Купівля великого бізнесу. |
| `Shopping` | 100 | Покупки | Придбання побутових і статусних активів. |
| `Expenses` | 125 | Витрати | Умовне або загальне списання. |
| `Chance` | 138 | Шанс | Можливості купівлі, разового доходу, шахрайські пропозиції та корупційні угоди. |
| `EventStore` | 124 фактично | Ринок | Продаж активів, розширення бізнесу, обвали ринку, перевибори й новини. Базова мапа має 110 карток, до неї додаються 14 продажів корупційних активів. |
| `Deputy` | 75 | Депутат | Платна спроба отримати депутатський голос. |

Під час створення дошки клієнт передає фактичний розмір кожної дефолтної колоди. Для згенерованої дошки ці самі розміри визначають кількість створених карток.

## Бізнеси

Малий, середній і великий бізнес мають однакову форму даних: назва, опис, ціна та регулярний прибуток. Після купівлі бізнес додається до активного доходу.

Прогресія на клітинці бізнесу:

- без бізнесу доступний малий бізнес;
- з малим бізнесом — малий або середній;
- із середнім — середній або великий;
- з великим — великий.

Робота зберігається як спеціальний бізнес `WORK`. Під час переходу в підприємництво гра може попросити підтвердити звільнення. Якщо гравець переходить між несумісними класами бізнесу без роботи, гра пропонує продати наявні бізнеси за їхньою ціною купівлі.

## Покупки

Картка `Shopping` має ціну та один із шести типів:

| `ShopType` | Актив | Постійний ефект |
|---|---|---|
| `ANIMAL` | Тварина | Додає регулярні витрати на утримання; активує витрати для власника тварини. |
| `AUTO` | Авто | Додає регулярні витрати й бонус руху, якщо транспортні бонуси ввімкнені. |
| `APARTMENT` | Квартира | Додає регулярні витрати та може бути умовою виходу на зовнішнє коло. |
| `HOUSE` | Будинок | Додає регулярні витрати та може бути умовою перемоги. |
| `YACHT` | Яхта | Додає регулярні витрати. |
| `FLY` | Літак | Додає регулярні витрати, найвищий транспортний бонус і може бути умовою перемоги. |

## Витрати

`Expenses` містить суму, тип платника й ознаку отримання тварини. Умова визначається за поточним станом активного гравця.

| `PayerType` | Хто платить |
|---|---|
| `ALL` | Усі. |
| `FREE_W_OR_MARRIED_M` | Неодружена жінка або одружений чоловік. |
| `AUTO_OWNER` | Власник авто. |
| `MEN` | Чоловік. |
| `PARENT` | Гравець із дітьми. |
| `MARRIED_M` | Одружений чоловік. |
| `APARTMENT_OWNER` | Власник квартири. |
| `APARTMENT_OR_HOUSE_OWNER` | Власник квартири або будинку. |
| `ANIMAL_OWNER` | Власник тварини. |

Якщо `grantsAnimal = true`, гравець після оплати отримує тварину. Якщо умова платника не виконується, картка завершується без списання.

## Шанс

Колода має шість механічних варіантів:

| Варіант | Дія |
|---|---|
| `RandomJob` | Одразу додає разовий прибуток готівкою. |
| `Estate` | Пропонує придбати об’єкт нерухомості або виставити можливість на аукціон. |
| `Land` | Пропонує придбати ділянку визначеної площі або виставити її на аукціон. |
| `Shares` | Пропонує придбати вибрану кількість акцій із доступного пакета; решта пакета лишається доступною в поточному сценарії. |
| `CorruptBusiness` | За депутатські голоси дозволяє купити корупційний бізнес із регулярним прибутком або разову оборудку. |
| `CorruptLand` | За депутатські голоси дозволяє купити корупційну землю. |
| `Scam` | Обіцяє неправдоподібну дохідність за негайний внесок. Гравець вкладає або відмовляється; виплата настає лише у `successPercentage` випадків. |

Корупційні картки `Chance` не випадають на внутрішньому колі. Разова корупційна оборудка одразу списує ціну й додає `oneTimeProfit`; вона не створює актив. Регулярний корупційний бізнес і земля зберігаються в гравця, можуть бути продані через ринок і роблять гравця вразливим до податкової.

## Події на ринку

`EventStore` має вісім механічних варіантів:

| Варіант | Дія |
|---|---|
| `Shares` | Власники відповідної компанії продають вибрану кількість акцій або відмовляються. При `forcedSale = true` кожен власник мусить продати весь пакет. |
| `Land` | Власники звичайної землі можуть продати вибрану площу за ціну одиниці. |
| `Estate` | Власники можуть продати вибрані об’єкти нерухомості за фіксовану ціну кожного. |
| `BusinessExtending` | Активний гравець додає зазначений регулярний прибуток до одного бізнесу. |
| `Reelection` | Обнуляє депутатські голоси всіх гравців. |
| `Announcement` | Інформаційна новина без прямого фінансового ефекту. |
| `MarketCrash` | Уцінює акції **всіх** гравців одночасно: уражений сектор втрачає `sectorDropPercentage`, решта — менший `marketDropPercentage`. Відмовитися не можна. |
| `CorruptBusiness` | Власники можуть продати один регулярний корупційний бізнес за відсоток від ціни купівлі. |
| `CorruptLand` | Власники можуть продати вибрану площу корупційної землі за підвищеною ціною одиниці. |

Перевибори й обидва корупційні продажі доступні лише на зовнішньому колі. Фільтрація для згенерованих колод виконується за механічним типом, а для старих дефолтних колод також підтримуються фіксовані ID.

Звичайні й корупційні продажі є спільними ринковими подіями: картка залишається активною, доки всі активні власники відповідного активу не продадуть або не відмовляться.

## Шахрайство

`Chance.Scam` — єдина картка, вигода якої свідомо від'ємна. Обіцяна дохідність (`promisedProfit / price`) лежить у діапазоні 150..900%, а ймовірність виплати — 1..20%. Валідація балансу вимагає, щоб очікувана віддача була нижчою за внесок, тож послідовна згода на такі пропозиції гарантовано розорює.

Внесок тримається нижчим за найдорожчу чесну можливість, щоб картка виглядала доступною. Купівля проходить звичайні серверні перевірки добровільної покупки.

## Обвал ринку

Компанії поділені на шість секторів (`core.energy`, `core.industry`, `core.consumer`, `core.realty`, `core.agro`, `core.tech`). `MarketCrash` обирає один сектор і уцінює всі портфелі. Генерація гарантує `marketDropPercentage < sectorDropPercentage` і бере сектор лише з тих, до яких насправді належать компанії партії.

## Депутати

Картка депутата має ознаку `corrupt`.

- Кожна спроба коштує `deputyCardPrice`.
- Корупційна картка додає один депутатський голос.
- Чесна картка не додає голосу, але гроші не повертаються.
- Після відкриття картки можна купувати наступну, доки дозволяють фінанси, або завершити хід.
- Голоси витрачаються на корупційні картки шансу.
- `Reelection` обнуляє всі голоси.

## Аукціон

Аукціон застосовується до можливості придбати бізнес, землю, нерухомість або акції.

1. Активний гравець оголошує стартову ставку.
2. Інші підключені гравці подають по одній актуальній ставці; нова замінює попередню ставку того самого гравця.
3. Мінімально допустима ставка дорівнює більшому зі стартової ставки та найвищої вже поданої. Ставка, рівна мінімальній, дозволена.
4. Для акцій ставка є ціною однієї акції, а учасник також задає кількість.
5. Власник можливості обирає ставку. Він отримує різницю між ставкою покупця та базовою ціною можливості; покупець набуває актив за своєю ставкою.
6. Для пакета акцій аукціон може продовжитися з залишком; для інших активів завершується після одного продажу.

## Життєвий цикл колоди

Дошка зберігає окремо draw pile і discard pile для кожного `BoardCardType`. Взята картка прибирається з draw pile, зберігається як `takenCard`, а наприкінці ходу переходить у скид. Якщо доступні картки закінчилися, дозволені картки зі скиду повертаються в draw pile. Порядок зараз не перемішується під час рециркуляції, але вибір картки виконується випадково.
