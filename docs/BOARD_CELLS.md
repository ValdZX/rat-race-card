# Клітинки дошки

## Структура кіл

Дошка має два циклічні треки. Порядок клітинок може бути згенерований для конкретної партії, але кількість і склад типів лишаються такими самими, як у дефолтній розкладці.

| Коло | Рівень | Клітинок | Призначення |
|---|---:|---:|---|
| Внутрішнє | 0 | 78 | Побудова cash flow, перші активи, сімейні події та звичайні ризики. |
| Зовнішнє | 1 | 74 | Великі бізнеси, депутати, корупційні угоди, мрії, податкова й фінальна стадія. |

Великі клітинки мають ознаку `isBig` і займають особливе місце у візуальній геометрії, але в доменній послідовності залишаються одним кроком.

## Повний перелік типів

| Тип | Коло | Ефект |
|---|---|---|
| `Start` — Старт | Обидва | Завершує хід. Якщо під час руху гравець пройшов старт і має фонди, відкриває капіталізацію. Точна зупинка дає підвищену ставку капіталізації. |
| `Salary` — Зарплата | Обидва, по 4 | Фіксує получку. При точній зупинці також відкриває високий, середній і низький інвестиційний ризик. |
| `Business` — Бізнес | Внутрішнє | Дозволяє взяти картку доступного рівня бізнесу. Набір колод залежить від найвищого поточного рівня бізнесу гравця. |
| `BigBusiness` — Великий бізнес | Зовнішнє | Відкриває лише колоду великого бізнесу. |
| `Shopping` — Покупки | Обидва | Відкриває картку покупки: тварина, авто, квартира, будинок, яхта або літак. |
| `Chance` — Шанс | Обидва | Відкриває можливість: підробіток, земля, нерухомість, акції, шахрайська пропозиція або корупційна угода. На внутрішньому колі корупційні варіанти відфільтровані. |
| `Expenses` — Витрати | Внутрішнє | Відкриває картку витрат. Гравець платить лише тоді, коли відповідає умові платника. |
| `Store` — Ринок | Обидва | Відкриває ринкову подію для акцій, землі, нерухомості, бізнесів, обвал ринку або загальну новину. Корупційні продажі та перевибори доступні лише зовні. |
| `Bankruptcy` — Банкрутство | Обидва | Видаляє один випадковий бізнес, крім роботи. Якщо таких бізнесів немає, нічого не відбувається. |
| `Child` — Дитина | Внутрішнє | Жінка або одружений чоловік отримує дитину й державну допомогу. Інші гравці проходять клітинку без ефекту. |
| `Love` — Кохання | Внутрішнє | Неодружений гравець одружується; чоловік сплачує вартість шлюбу. Для одруженого гравця ефекту немає. |
| `Rest` — Відпочинок | Внутрішнє | Встановлює кількість майбутніх пропусків ходу `restTurnCount`. |
| `Divorce` — Розлучення | Внутрішнє | Припиняє шлюб. Для чоловіка додатково обнуляє дітей і зменшує готівку та депозит до визначеного відсотка. |
| `Resignation` — Звільнення | Внутрішнє | Видаляє роботу `BusinessType.WORK`; інші бізнеси залишаються. |
| `Desire(dreamId)` — Мрія | Зовнішнє, 22 | Пропонує купити конкретну непридбану мрію. Якщо її вже купили, хід завершується без пропозиції. |
| `Deputy` — Депутат | Зовнішнє | Дозволяє платно брати картки депутатів або пропустити клітинку. Корупційна картка додає голос, чесна — ні; ціна стягується в обох випадках. |
| `TaxInspection` — Податкова | Зовнішнє | Якщо є хоча б один корупційний бізнес або корупційна земля, списує 20% загальних статків і показує суму відкупного. Без корупційних активів ефекту немає. |

## Важливі переходи стану

Клітинка не повинна напряму змінювати чергу на клієнті. Сервер виконує ефект і викликає перехід ходу лише після завершення сценарію. Для карткових клітинок стан дошки проходить послідовність:

`canTakeCard` → `takenCard` → дія картки або відмова → скид → наступний гравець.

Ринкові картки можуть чекати відповіді кількох власників активу. Для цього дошка веде `processedPlayerIds`; хід завершується, коли всі відповідні активні гравці продали або відмовилися.

## Обмеження поточної реалізації

- Дефолтні списки клітинок зберігаються безпосередньо в `Place.kt`, а `BoardLayer` лишається legacy-константою двох базових кіл.
- Кількість треків уже не обмежена: правила клітинок реєструються за `CellTypeId`, а розкладка будується `TrackLayoutEngine` для довільного списку треків.

Стан міграції описаний у [плані архітектурного рефакторингу](ARCHITECTURE_REFACTORING.md).
