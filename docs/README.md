# Документація Rat Race Card

Цей каталог описує гру такою, якою вона реалізована в коді станом на 6 серпня 2026 року. Сервер є джерелом істини для онлайн-партії; клієнт лише показує стан і надсилає команди. Якщо текст документації суперечить реалізації, пріоритет має серверна доменна логіка, а розбіжність слід виправити в документації або зафіксувати як зміну правил.

## Два режими застосунку

Проєкт містить дві незалежні ігрові системи:

1. **Онлайн-дошка** — повна покрокова гра для кількох гравців. Стан зберігає сервер, правила виконує `RaceRatServiceImpl`, клієнт працює через `BoardViewModel`.
2. **Локальна картка гравця** — цифровий фінансовий лист для фізичної настільної гри. Стан зберігається локально через KStore, а дії обробляє `RatRace2CardStore`. Цей режим не має дошки, колод і серверного циклу ходів.

Правила клітинок і колод у цій документації стосуються онлайн-дошки. Фінансові формули спільні: локальний режим працює через `OfflineFinanceAdapter` поверх того самого `MoneyService` і `FinancialSnapshot`, тому зміна балансової формули діє в обох режимах.

## Термінологія

| Термін | Значення |
|---|---|
| Баланс рахунку | Готівка + депозит + суми у фондах. |
| Загальні статки | Готівка + депозит + фонди + акції за ціною купівлі + бізнеси за ціною купівлі − кредит. Земля та нерухомість у цю формулу зараз не входять. |
| Cash flow | Увесь активний і пасивний дохід мінус регулярні витрати. |
| Індекс цін | Накопичений множник інфляції. Діє на витрати, прибуток бізнесів і порогові умови. |
| Індекс зарплати | Накопичений множник зарплати. Відстає від індексу цін на задану частку. |
| Сектор | Група компаній, яку одночасно уражає обвал ринку. |
| Журнал партії | Послідовність фінансових зрізів гравця, на якій будується підсумковий екран. |
| Трек | Одне коло дошки, `TrackDefinition` зі стабільним `TrackId`. Кількість треків у партії не обмежена. |
| Внутрішнє коло | Стартовий трек, `TrackId("inner")`. |
| Зовнішнє коло | Наступний трек, `TrackId("outer")`. |
| Ринок | Колода `EventStore`, тобто події на ринку. |
| Шанс | Колода можливостей `Chance`. |
| Корупційний актив | Корупційний бізнес або корупційна земля, придбані за депутатські голоси. |
| Депутатський голос | Лічильник `Player.deputies`, який витрачається на корупційні угоди. |

## Підтримка документації

Зміна доменної механіки має включати оновлення відповідного документа. Новий тип клітинки описується в `BOARD_CELLS.md`, новий вид картки — у `CARDS.md`, нова формула або балансова константа — в `ECONOMY.md`. Архітектурні рішення під час рефакторингу слід оформлювати як ADR у майбутньому каталозі `docs/adr/`.
